Scénario

Gestion d'un scénario

Configuration​

Options communes à tous les widgets (voir Gestion des widgets) : Nom, Nom d'affichage, Sous-titre, Image, Images sous conditions, Affichage forcé.

OptionTypeObligatoireDescription
ScénarioScénarioOui
Widgets supplémentairesListe de widgetsWidgets supplémentaires affichés dans la vue détails
Masquer l'appareilCase à cocher[Android 11+] Ne pas remonter ce widget dans les appareils contrôlés par Android
Contrôle depuis l'écran de verrouillageCase à cocher[Android 13+] Autorise le contrôle de l'appareil depuis l'écran de verrouillage

Variables pour textes dynamiques​

Utilisables dans le nom, le sous-titre et les conditions (voir Textes dynamiques).

VariableDescription
#room#Pièce
#active#Scénario actif (0 ou 1)
#running#En cours d'exécution (0 ou 1)
