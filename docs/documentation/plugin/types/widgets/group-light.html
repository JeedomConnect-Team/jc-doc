Groupe de lumières

Gère un groupe de plusieurs widgets lumières

Configuration​

Options communes à tous les widgets (voir Gestion des widgets) : Nom, Nom d'affichage, Sous-titre, Image, Images sous conditions, Affichage forcé.

OptionTypeObligatoireDescription
WidgetsListe de widgetsOuiListe des lumières à gérer
Widgets acceptés : Lumière On/Off, Lumière à variation, Lumière de couleurs
Arrière plan automatiqueCase à cocherAffiche un arrière plan automatique en fonction de l'état de la lumière
Sécuriser action ONSécurisation
Sécuriser action OFFSécurisation

Variables pour textes dynamiques​

Utilisables dans le nom, le sous-titre et les conditions (voir Textes dynamiques).

VariableDescription
#room#Pièce
#statusText#Statut 'Eteint' ou 'Allumé'
#onNb#Nombre de lumières allumées
#offNb#Nombre de lumières éteintes
#total#Nombre de lumières
