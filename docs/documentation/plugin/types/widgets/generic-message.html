Générique message

Permet l'utilisation d'une commande de type message

Configuration​

Options communes à tous les widgets (voir Gestion des widgets) : Nom, Nom d'affichage, Sous-titre, Image, Images sous conditions, Affichage forcé.

OptionTypeObligatoireDescription
ActionCommande action messageOuiCommande executée avec les informations 'message' saisies
Champ TitreCase à cocherEst ce qu'une zone 'titre' doit être affichée sur le widget
Garder le dernier messageCase à cocherConserver le dernier message envoyé pour ne pas avoir à le retaper
Image EnvoyerImageChoix de l'icône à utiliser pour le bouton 'envoi'
Widgets supplémentairesListe de widgetsWidgets supplémentaires affichés dans la vue détails
