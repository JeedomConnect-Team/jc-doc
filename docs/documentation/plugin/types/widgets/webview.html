Web View

Permet d'afficher un design, le dashboard ou n'importe quelle page Web. Astuce : Pour un affichage direct dans un menu, configurez l'affichage forcé sur Détail (ce widget doit être unique dans le menu)

Configuration​

Options communes à tous les widgets (voir Gestion des widgets) : Nom, Nom d'affichage, Sous-titre, Image, Images sous conditions, Affichage forcé.

OptionTypeObligatoireDescription
URLTexteEntrez ici l'ID d'un design (nombre entier), le mot clé 'dashboard', ou bien une URL de votre choix
URL localeTexteURL utilisée lorsque l'appareil est sur le même réseau que Jeedom
Commande URLCommande info texteCommande info contenant l'URL à afficher
Afficher dans la grilleCase à cocherAffiche la page web dans la tuile
HauteurTexteHauteur de la vue en mode carte en grille standard (par défaut 200)
Cacher la barre du haut en vue détailCase à cocher
Injection JSTexteInjecter du code JavaScript dans la page après son chargement
Désactiver l'accélération matérielleCase à cocherDésactivez si vous rencontrer des problèmes
